# Simple Color Dots

An Obsidian plugin that puts a colored dot at the start of a line, to mark statuses, tasks and important places in your notes.

## Usage

In editing mode, right-click a line → **Dot color…** → pick a color or **Remove dot**. On a Mac trackpad, click with two fingers.

The dot goes right before the text, so lists, tasks, headings, quotes and callouts keep their formatting.

## Installation

1. Download `main.js` and `manifest.json` from the latest release.
2. Put them in `.obsidian/plugins/simple-color-dots/` in your vault.
3. Enable the plugin in **Settings → Community plugins**.
